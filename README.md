Overview:
This is a simple program to download pdf's from https://www.scribd.com.
There are more professional tools, just google scribd downloader

Instalation:
Unix:
git clone https://github.com/PodlaskiAsasyn-notAI/scribd_PDF-downloader
pip install -r requirements.txt

Usage:
python main.py "scibd_URL" --output "path_to_your_output.pdf"

Program automatically caches images and source code, so in case of problems, clear cache folder
